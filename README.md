# 📊 CC3084 — Data Science

Repositorio con laboratorios, proyectos y ejercicios desarrollados durante el curso **CC3084 - Data Science** de la **Universidad del Valle de Guatemala (UVG)**.

El repositorio reúne parte del trabajo realizado durante el curso. Cada laboratorio aborda un problema distinto, por lo que las herramientas, datasets y métodos utilizados pueden variar entre carpetas.

## 🧠 Contenido

Entre los temas trabajados se encuentran:

* Análisis y limpieza de datos
* Análisis exploratorio de datos (EDA)
* Series de tiempo
* Machine Learning y Deep Learning
* Redes neuronales y LSTM
* Visualización de datos
* Otros temas y herramientas de Data Science

## 📂 Estructura

Actualmente el repositorio contiene trabajos como:

```text
Data_Science/
├── Lab-DeepLearning/
├── Lab1_SeriesDeTiempo/
├── Proyecto1/
└── Series de Tiempo/
```

Las carpetas pueden contener **Jupyter Notebooks, código fuente, datasets, imágenes, archivos de requerimientos y documentación** según lo solicitado en cada actividad.

Cuando corresponde, cada laboratorio cuenta con su propio `README.md` con información más específica sobre el problema, metodología y resultados.

## 🛠️ Herramientas

Principalmente se utiliza **Python** y **Jupyter Notebook**, junto con distintas librerías y herramientas de análisis de datos, visualización y aprendizaje automático según las necesidades de cada actividad.

## 📌 Nota

Este repositorio no contiene necesariamente todo el material del curso y se irá actualizando conforme se desarrollen nuevos laboratorios y proyectos.

El contenido tiene fines **académicos y educativos**.
